# Windows Recon Basics 🕵️‍♂️

A beginner-friendly batch script for basic system enumeration on Windows.

## 📌 Features

* Displays current user
* Collects system information
* Shows network configuration
* Lists running processes
* Displays active network connections

## ⚙️ Usage

1. Download the script
2. Run `recon.bat`
3. Check the generated `recon_results.txt`

## 🎯 Purpose

This project is intended for:

* Learning cybersecurity fundamentals
* Understanding system enumeration
* Practicing basic scripting

## ⚠️ Disclaimer

This script is for educational and authorized use only. Do not run it on systems you do not own or have permission to test.

## 🛠️ Commands Used

* `whoami`
* `systeminfo`
* `ipconfig`
* `tasklist`
* `netstat`
